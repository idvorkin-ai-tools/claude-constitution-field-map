The order at work

Change the features of one request and watch which layer of the constitution decides it, and why the document weighs holistically instead of ranking strictly.

A request first meets a filter: if it is a flagrant case of one of the seven hard constraints, it is declined and nothing else is weighed. Otherwise safety, ethics, Anthropic's guidelines and helpfulness are balanced together, with the higher ones heavier but none of them reduced to a tie-breaker.

Pick one of the document's own cases, then change it. Every control is a feature of the case; the panel shows the verdict, the layer that decided it, the pulls in the balance, and one line on what your last change did.

Weighing rule

    "if anything, a persuasive case for crossing a bright line should increase Claude's suspicion that something questionable is going on."— Claude's constitution, Hard constraints
    "rather than only viewing lower priorities as “tie-breakers” relative to higher ones."— Claude's constitution, Claude's core values

    The numbers are this explorable's illustration, not the document's: the constitution gives no weights. Here an ethical cost counts four times, an applicable guideline two points, and benefit one point per step, adjusted by the operator (+1 allows, −2 restricts) and the user's claim (+1 plausible, −1 implausible). The verdicts for the preset cases are the document's; the arithmetic is only a way to make "higher generally dominates, lower still counts" visible.

    Things to try

    • Load Nurse, no system prompt, then set the operator to "restricts or signals caution" and nudge expected harm to 1. The verdict moves from help to decline inside the weighing. Notice that the same question gets different answers because the context changed, not because a rule fired.
    • Load Nurse, ICU operator and switch the weighing rule to strict. Under strict ranking the small ethical cost decides on its own and the answer becomes decline; under holistic, the large benefit outweighs it. Notice that this gap is exactly what the document rejects when it says lower priorities are not tie-breakers.
    • Load Vaccine researcher: the argument box is locked and the high benefit and plausible claim are never weighed. Set the filter to "unclear" and the case drops into the weighing instead; tick the argument box there, then set the filter back to "flagrant". Notice that the box locks again and the suspicion rule appears: the filter is not a heavy weight but a gate, and it closes only for flagrant or quite likely cases.
    • Load Anthropic pauses a task and push the benefit of continuing to 3. The verdict holds. Notice that safety decides before the merits of the task are weighed, and that the verdict still includes saying so if Claude disagrees.
    • Load User text claiming to be Anthropic, then set oversight to "nothing" and the operator to "allows". Notice the difference between a claimed authority in the user's turn, which gets user-level trust, and a real operator permission, which is weighed.
    • Load Fraud found mid-task. Notice that the explorable stops at "lean to decline": the document's answer is about how to decline (raise concerns, ask, or stop before starting, not drastic unilateral action), which no weight can show.
