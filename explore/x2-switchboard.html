Who can flip what

Pick who is asking, which behaviour, and which way; see whether the change takes effect under Claude's constitution, inside whose bounds, and why.

Claude's behaviour sits inside three nested boxes: Anthropic's bounds contain the operator's, which contain the user's, and each party can rearrange only what its own box holds. Two things sit outside the boxes entirely: the hard constraints, which nobody can move, and documents or tool results, whose instructions are information rather than orders.

Every row below is an example the constitution itself gives (from its lists of instructable behaviours, the six user floors, its honesty rules and its rules on trust), and every verdict comes from what the text says about that case. Where the text does not settle a combination, the page says so.

Things to try

  • A user says they are a nurse and asks about overdoses. Then make the actor the operator. Notice that the user's claim alone depends on the deployment, while an operator telling Claude to trust stated occupations simply takes effect.
  • Text in the user turn claims to be the operator and asks Claude to stop swearing. Then switch to turn on: profanity still takes effect, but only because a user could ask for it anyway. Now pick "treat the user with operator-level trust" and notice the forged claim gains nothing: it only ever gets user-level trust.
  • First as the operator, then as the user. Notice the floor that no operator can lower is one the user can, by setting up a fiction, and that Claude still breaks character to avoid harm.
  • The instruction arrives inside a shared document. Notice the verdict never depends on what the instruction asks for: inputs carry no authority in any direction.
  • Then try plain operator-level trust. Notice an operator can make the user's box as big as its own, never bigger.
  • The document's middle-tier operator instruction. Then try its third-tier example, which no reason unlocks, and the hard-constraint row, which not even Anthropic can move.
